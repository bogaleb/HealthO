# ADR-0005 — Stack and dependency selection

**Status:** Accepted (Phase 0, 2026-10-20). Versions are pinned exactly (`.npmrc save-exact=true`, `pnpm-lock.yaml`).

| Concern | Choice | Version | Notes |
|---|---|---|---|
| Runtime | Node.js | 22 LTS | `engines.node >= 22` |
| Package manager | pnpm workspaces | 10.28 | |
| Web | Next.js App Router | 15.5.28 | Stayed on 15.x (mature, well-known APIs) rather than 16.x |
| UI | React 19.2, Tailwind CSS 4.3, lucide-react | | shadcn-style components hand-written in `packages/ui` (no CLI/registry dependency) |
| DB | PostgreSQL 16 + Drizzle ORM 0.45 + postgres.js 3.4 | | SQL migrations generated by drizzle-kit 0.31, plus hand-written SQL for triggers |
| Auth | Better Auth 1.7 | | Email/password, DB sessions in httpOnly cookies, rate limiting, sign-up disabled. Chosen over Auth.js (credentials provider lacks DB sessions) and Lucia (deprecated). MFA/passkeys plugin available for the PHI gate. |
| Validation | Zod 4 | | Shared schemas in `packages/shared` |
| Tests | Vitest 3.2, Playwright 1.56 | | Playwright pinned to match the CI/dev Chromium build |

`kysely` is installed alongside drizzle-orm in each package so pnpm resolves a single drizzle-orm instance (Better Auth declares it as an optional peer).
