# ADR-0003 — Authoritative appointment source

**Status:** Proposed — decision required before Phase 4/7

Per blueprint §4.5 each site will run in one mode: `DEMO`, `READ_ONLY`, `EHR_MASTER`, `STANDALONE_APPROVED`. Until the organization names its EHR, confirms vendor API capabilities and signs off on the source of truth, all sites are `DEMO` and no appointment is described as synced. No code for this exists yet (Phase 4+).
